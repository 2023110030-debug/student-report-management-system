# Student Report Management System

An open-source web application for managing internship reports, work practice reports, student documentation, and project submissions.

## Features

- User Authentication
- Report Upload
- Document Management
- Progress Tracking
- Dashboard
- Admin Panel
- Search Reports
- Download Documents

## Technology

- HTML
- CSS
- JavaScript
- PHP
- MySQL

## Installation

```bash
git clone https://github.com/yourusername/student-report-management-system.git
```
